# The Learning Curve Approach

Verktyg för Sense, See och Shift i Smart Built Boost.
Publiceras på https://boost.mickla.se

© Engströms Mickla AB 2026

## Struktur

- `index.html`, `js/app.js`, `js/content.js`: landningssidan. Texterna redigeras i `js/content.js`.
- `see/`: Dialogverktyget (See). Texterna redigeras i `see/content.js`.
- `sense/`, `shift/`, `slut/`: kommande moduler och slutsida.
- `js/lca.js`: det gemensamma sparformatet som modulerna använder för att lämna underlag till varandra.
- `css/style.css`: utseendet, gemensamt för alla sidor.
- `vendor/`: jsPDF och svg2pdf.js (MIT-licens), lokalt för att inga besökare ska skickas till tredje part.
- `CLAUDE.md`: arbetsbeskrivning, beslut och principer för vidareutvecklingen.

Ingen data lämnar besökarens webbläsare. Sidan har ingen statistik, inga cookies och inga externa typsnitt.
